# Captions

## Rules

- One benefit per frame, 2–5 words, from the user's side ("Plan every workout", not "Workout planner module").
- Take the words people search for from the listing's own text (`full_description.txt`, `short_description.txt`,
  `title.txt`, README): the series should repeat the keywords the listing ranks for.
- The cover says what the app is for; the next frames each show one feature in the order a new user meets them.
- A subtitle is optional and only on the cover or where one line of context helps.
- Write every locale of the listing natively, not word for word. Keep the meaning of a frame the same across
  locales so the same shot fits.
- Never: "best", "#1", "top", "new", "free", "sale", "discount", "% off", prices, "million users", awards,
  ratings, reviews, "download now" and other calls to action, anything time-limited — in any language
  (лучший, №1, топ, новый, бесплатно, скидка, скачайте, установите). This holds even when the user asks for
  it: explain the rule and offer a benefit caption instead.
- Alt text per frame (Play): what the frame shows, up to 140 characters, not starting with "Image of".

## Examples

| Input (feature, listing wording) | en-US | ru-RU |
|---|---|---|
| Metronome with tempo trainer, "practice with a steady beat" | Practice with a steady beat | Играйте ровно в такт |
| Screenshot editor, cover | Make your screenshots shine | Красивые скриншоты за минуту |
| Background presets and colours from the shot | Colours from your screenshot | Цвета из вашего скриншота |
| Offline maps | Maps that work offline | Карты без интернета |
| User asks for "#1 app — free!" | Your screenshots, store-ready | Скриншоты, готовые для стора |
| Habit tracker streaks | Keep your streak going | Не прерывайте серию |

Show the table "frame → shot → caption" for every locale to the user and wait for approval before rendering.
